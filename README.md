# Solar System

A visual representation of the solar system with orbiting planets and generated stars.

## Author

**Shivansh**

## Tech Stack

- **HTML5**: For the structure of the solar system.
- **CSS3**: For styling, animations (orbits), and layout.
- **JavaScript**: For dynamically generating background stars.

## Features

- CSS-based orbit animations for planets.
- Dynamic star generation using JavaScript.
- Responsive design principles.
